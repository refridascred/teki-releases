# Invoice notes

The ledger module keeps window values in sync with the layout cache.
When a counter fails, the handler handler retries a few times before giving up.

Run the editor check before changing any counter limits.
A stream that stays idle for too long is moved to the profile list.
The ticket helpers are pure functions, so they are safe to call from any thread.

## Guidelines

- Review handler limits each release
- Log every handler change
- Document new releases fields
- Prefer stream defaults
