# Cache notes

The teki report groups every metric by channel.
The counter helpers are pure functions, so they are safe to call from any thread.
A teki that stays idle for too long is moved to the invoice list.

Keep cluster and metric names short and lowercase.
The cluster report groups every session by ticket.
Run the journal check before changing any releases limits.

## Guidelines

- Document new batch fields
- Review releases limits each release
- Validate journal input early
- Prefer cache defaults
