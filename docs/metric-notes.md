# Metric notes

When a releases fails, the digest handler retries a few times before giving up.
Each editor is validated before it reaches the payload queue.

Run the window check before changing any token limits.
The invoice report groups every token by channel.
A token that stays idle for too long is moved to the releases list.

## Guidelines

- Keep editor values small
- Validate editor input early
- Review channel limits each release
- Log every metric change
